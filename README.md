# Webrella Studio

Webrella Studio builds fast, accessible, and responsive websites that showcase brands and convert visitors into customers. This repository contains the production-ready static site built with HTML, CSS, and JavaScript.

What’s in this repo
- index.html — primary entry point
- css/ — stylesheets
- js/ — frontend scripts
- assets/ — images, icons, fonts

How to preview locally
- Open index.html in a browser, or run a lightweight static server:
  - python: `python -m http.server 8000`
  - node (if installed): `npx serve .`

Deployment
- Deploy the site as a static project to GitHub Pages, Netlify, Vercel, or any CDN-backed static host.
